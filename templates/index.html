About the project

Turning Racing Data Into Intelligence.

F1 Race Intelligence combines Tableau's interactive data visualization with Flask's lightweight web framework.

The published Tableau dashboard is embedded in an HTML template and displayed through a Flask route. This makes the analysis accessible through a single website.

The project demonstrates how web development and data visualization can work together to present motorsport analytics in an accessible, interactive format.
